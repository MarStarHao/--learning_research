💡 实用技巧
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  选择合适的编码器
  ────────────────────────────
    场景                     推荐编码器
    ──────────────────────────────────────
    追求最佳性能             → Transformer
    处理长序列               → Conv
    快速原型/基线            → MLP
    实时应用                 → Conv
  
  
  调整训练参数
  ────────────────────────────
    参数              建议值                说明
    ────────────────────────────────────────────────
    num_timesteps    500-1000             扩散步数
    batch_size       32-128               批次大小
    lr               1e-4 ~ 3e-4          学习率
    encoder_type     transformer          编码器类型
    schedule_type    cosine               噪声调度
  
  
  提升性能的方法
  ────────────────────────────
    ✓ 使用余弦噪声调度 (schedule_type='cosine')
    ✓ 增加训练轮数 (num_epochs=200)
    ✓ 使用对比学习 (use_contrastive=true)
    ✓ 增加模型容量 (encoder_dim=512)

❓ 常见问题
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Q1: 训练很慢怎么办？
  ────────────────────────────
  A: • 减少 num_timesteps (1000→500)
     • 使用 Conv 编码器
     • 增加 batch_size
     • 减少 encoder_layers
  
  
  Q2: 内存不足？
  ────────────────────────────
  A: • 减小 batch_size
     • 使用 MLP 编码器
     • 减少 seq_len
     • 关闭注意力机制
  
  
  Q3: 如何用自己的数据？
  ────────────────────────────
  A: 参考 data/dataset.py 中的 TimeSeriesDataset
     
     from data import TimeSeriesDataset
     dataset = TimeSeriesDataset(
         data=your_data,  # numpy array
         seq_len=100,
         normalize=True
     )
